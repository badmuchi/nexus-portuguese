# AGENTS.md — Правила архитектуры и разработки (Portuguese App)

Этот проект — приложение для изучения португальского языка на базе **Flutter** с архитектурой **Clean Architecture (Feature-first)**. Любой сгенерированный или изменённый код обязан строго соответствовать текущей структуре, стеку и паттернам проекта.

## 1. Технологический стек
- **UI и фреймворк:** Flutter (Material Design), строгий LTR (`TextDirection.ltr`).
- **Стейт-менеджмент:** `flutter_bloc` (`^9.1.1`) + `equatable` (`^3.0.0`).
- **Локальная БД:** `drift` (`^2.24.0`) + `drift_flutter` (`^0.3.0`), кодогенерация через `build_runner` и `drift_dev`.
- **Сеть и хранение:** `dio` (`^5.9.2`), `flutter_secure_storage` (`^10.2.0`).
- **Аудио и речь:** `just_audio` (`^0.10.5`), `flutter_tts` (`^4.2.5`).
- **Тестирование:** `flutter_test`, `bloc_test` (`^10.0.0`), `mocktail` (`^1.0.5`).

## 2. Структура проекта (`lib/`)
- `lib/core/` — общие модули, переиспользуемые во всех фичах:
  - `audio/` — гибридное воспроизведение (`HybridAudioPlaybackService`, TTS, `just_audio`).
  - `database/` — схема БД Drift (`app_database.dart`, `app_database.g.dart`).
  - `error/` — типизированные ошибки (`Failures`).
  - `logging/` — централизованный логгер.
  - `notifications/` — локальные напоминания и уведомления об обучении.
  - `result/` — обёртка `Result<T>` для безопасного возврата успеха/ошибки.
  - `settings/` — локальные настройки приложения.
  - `speech/` — распознавание речи и оценка произношения.
  - `utils/` — общие утилиты и хелперы для португальской орфографии/диакритики.
  - `widgets/` — переиспользуемые UI-компоненты.
- `lib/features/<feature>/` — изолированные функциональные модули (`home`, `grammar`, `listening`, `slang`, `progress`, `speech_lab`, `srs`, `stories`, `phonetics`, `dictionary`, `morphology`, `conversation`):
  - `data/` — модели данных, мапперы, реализации репозиториев, чтение сидов.
  - `domain/` — сущности, интерфейсы репозиториев, бизнес-логика.
  - `presentation/` — BLoC/Cubit (`*_bloc.dart`, `*_event.dart`, `*_state.dart`), экраны и виджеты.

## 3. Ассеты и данные
- **JSON-сиды:** `assets/seed/` (`dialogues_seed.json`, `dictionary_seed.json`, `grammar_verbs_seed.json`, `listening_seed.json`, `srs_seed.json`, `stories_seed.json`, `slang_seed.json`, `phonetics_seed.json`).
- **Аудиофайлы:** `assets/audio/` (`dialogue/`, `listening/`, `srs/`, `slang/`).
- При добавлении новых сидов или аудио-папок обязательно регистрируй их в `pubspec.yaml`.

## 4. Жёсткие правила и ограничения
1. **Обработка ошибок через `Result`:** Репозитории не должны пробрасывать необработанные исключения в UI. Все операции возвращают `Result<T>` с конкретным `Failure` из `core/error/`.
2. **Никакой логики в UI:** Виджеты в `presentation/` не обращаются к БД или сети напрямую — только отправляют события в BLoC и рендерят состояния.
3. **Кодогенерация Drift:** Никогда не редактируй `*.g.dart` вручную. После изменения таблиц в `core/database/` запускай:
   `dart run build_runner build --delete-conflicting-outputs`
4. **Специфика португальского языка:** Не используй утилиты для иврита (`unorm_dart`, никкуд, RTL). При сравнении и поиске португальских слов учитывай диакритику (`ã`, `õ`, `ç`, `á`, `é`, `í`, `ó`, `ú`, `â`, `ê`, `ô`) и регистр, но сохраняй оригинальное написание при отображении.
5. **Аудио и TTS:** Используй существующие абстракции из `core/audio/` и `core/speech/` (настраивая локаль `pt-BR` или `pt-PT` согласно настройкам пользователя), не вызывай `AudioPlayer` напрямую из виджетов.
6. **Верификация:** Перед завершением любой задачи запускай `flutter analyze` и актуальные тесты (`flutter test`).
