# Core Technical Rules
1. **Database (Drift):** Для работы с локальными данными строго используй `drift` и `drift_flutter`. При изменении таблиц или DAO всегда напоминай или запускай `/opt/homebrew/share/flutter/bin/flutter pub run build_runner build --delete-conflicting-outputs`.
2. **State Management & Architecture:** Придерживайся чистой модульной архитектуры (feature-first). Разделяй UI-виджеты, бизнес-логику (Bloc/Cubit) и слой работы с БД/репозиториями. Избегай излишнего усложнения и устаревших API Flutter.
3. **Code Quality:** Весь код должен проходить `flutter analyze` без предупреждений. Используй строгую типизацию, `const`-конструкторы везде, где это возможно, и актуальный Material 3.

# Portuguese & UI Specifics (КРИТИЧНО)
1. **Диалекты (PT-BR vs PT-PT):**
   - Основной упор на бразильский португальский (PT-BR), но с поддержкой европейского (PT-PT) через пометки, тумблер в настройках и специфические карточки/диалоги.
   - Учитывай лексические различия (BR *ônibus* / PT *autocarro*, BR *trem* / PT *comboio*, BR *celular* / PT *telemóvel*).
   - Учитывай грамматические различия (BR *estou fazendo* / PT *estou a fazer*; местоимения *você* / *tu*).
2. **Фонетика & Диакритика:**
   - Полноценная поддержка диакритических знаков (`á`, `à`, `â`, `ã`, `é`, `ê`, `í`, `ó`, `ô`, `õ`, `ú`, `ç`).
   - При проверке письменного ввода нормализовать текст (уметь сопоставлять как с диакритикой, так и показывать подсказку, если акцент пропущен).
   - Поддержка TTS для локалей `pt-BR` и `pt-PT`.
3. **Грамматический фокус:**
   - 3 спряжения (`-ar`, `-er`, `-ir`), неправильные глаголы, времена индикатива и сослагательное наклонение (*Subjuntivo*).
   - Слияния предлогов (*Contrações*): `do`, `da`, `no`, `numa`, `pelo`, `à` (*crase*).
