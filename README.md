# Nexus Portuguese App 🇧🇷 🇵🇹

Оффлайн-ориентированное приложение для изучения португальского языка (универсальный гибрид Бразильского PT-BR и Европейского PT-PT) на Flutter + Drift (SQLite) с чистой архитектурой (Clean Architecture / DDD).

## Архитектура и стек технологий

- **Фреймворк:** Flutter 3.50+ / Dart 3.14+ (Material 3).
- **База данных:** Drift 2.24+ / `drift_flutter` (SQLite) с генерацией типизированных таблиц и автосидированием из JSON-файлов в `assets/seed/`.
- **Интервальные повторения:** Алгоритм **FSRS** (Free Spaced Repetition Scheduler).
- **Стейт-менеджмент:** BLoC / Cubit (`flutter_bloc`).
- **Аудио & Произношение:** Гибридный сервис озвучки (`flutter_tts` + `just_audio`), поддержка локалей `pt-BR` и `pt-PT`, оценка точности произношения (расстояние Левенштейна и точность по словам).

## Реализованные модули

1. **Главная (Home):**
   - Слово дня (*Palavra do Dia*) с переводом, примером и озвучкой.
   - Сетка быстрого доступа ко всем разделам.
   - Тумблер переключения диалекта (PT-BR 🇧🇷 vs PT-PT 🇵🇹).
   - Счётчик карточек к повторению и культурные советы.

2. **Диалоги (Conversation):**
   - Интерактивные ветвящиеся диалоги в реальных локациях (Кафе в Лиссабоне, Пляж Копакабаны в Рио).
   - Озвучка реплик и интерактивная тренировка произношения с оценкой точности речи.

3. **FSRS Карточки (Spaced Repetition):**
   - Интервальные повторения карточек с алгоритмом FSRS.
   - Два режима: классический флип-карточки и режим ввода с клавиатуры.
   - Проверка диакритики: подсказка, если буквы верны, но пропущены ударения (`á`, `é`, `õ`, `ç`).
   - 4 градации оценки: *Novamente*, *Difícil*, *Bom*, *Fácil*.

4. **Грамматика (Grammar):**
   - Атлас спряжения глаголов (группы `-ar`, `-er`, `-ir` и неправильные `ser`, `estar`, `ter`, `ir`, `fazer`, etc.).
   - Смена времен: *Presente*, *Pretérito Perfeito*, *Pretérito Imperfeito*, *Futuro do Presente*, *Presente do Subjuntivo*.
   - Интерактивная матрица слияния предлогов (*Contrações*: `do`, `da`, `no`, `numa`, `pelo`, `à`).
   - Разбор культовой дилеммы *Ser vs Estar*.

5. **Аудирование и диктанты (Listening):**
   - Прослушивание фраз на нормальной (1.0x) и замедленной (0.75x) скорости.
   - Поле диктанта для проверки правописания на слух.

6. **Словарь (Dictionary):**
   - Оффлайн полнотекстовый поиск по португальским и русским словам.
   - Фильтрация по частям речи и возможность добавлять собственные слова.

7. **Фонетический атлас (Phonetics):**
   - Тренажер носовых гласных и дифтонгов (`-ão`, `-ãe`, `-õe`, `-am`).
   - Правила открытых и закрытых гласных (`é/ê`, `ó/ô`).
   - Особенности чтения согласных `r/rr`, `s/z/x`, `ç`.
   - Контрасты Бразилии и Португалии (*d/t* как дж/ч, *l* как у, редукция гласных).

8. **Истории и тексты (Stories):**
   - Чтение с параллельным скрываемым переводом и кликабельным разбором слов.

9. **Сленг и идиомы (Slang & Gírias):**
   - Разбор популярных выражений Бразилии и Португалии (*Legal vs Fixe*, *Cara vs Gajo*, *Tirar o cavalinho da chuva*, *Ficar a ver navios*).

10. **Прогресс (Progress):**
    - Сводка по всем активностям, статистика карточек, диалогов и грамматики.

11. **ETL Tools (`tool/`):**
    - Python-скрипты для сбора и импорта открытых баз (Tatoeba, Wiktionary).

## Команды для запуска

```bash
# Проверка зависимостей
flutter pub get

# Генерация кода базы данных Drift
/opt/homebrew/share/flutter/bin/flutter pub run build_runner build --delete-conflicting-outputs

# Проверка анализатора (должен быть чистый результат)
/opt/homebrew/share/flutter/bin/flutter analyze

# Запуск тестов
/opt/homebrew/share/flutter/bin/flutter test

# Запуск приложения на macOS / Web / устройствах
/opt/homebrew/share/flutter/bin/flutter run
```
